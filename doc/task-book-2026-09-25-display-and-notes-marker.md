# 显示器窗口记忆与笔记目录标记任务书（2026-09-25）

## 目标

修正多显示器分辨率切换时窗口位置和尺寸恢复不合适的问题，并在文档中说明 `.flashsticknote` 的用途。实施前保留用户本机配置和笔记数据；窗口比例改动需加入自动化回归。

## D1 按显示区域比例记忆窗口矩形

**现状**：`MainWindow` 将 `Left`、`Top`、`Width`、`Height` 直接保存到 `conf.json`，恢复时按绝对值应用。显示器分辨率、工作区或 DPI 变化后，窗口可能太大、位置偏移或移出可见区域。

**目标**：使用一组共用比例记忆窗口矩形，不为各显示器保存独立值。保存时按窗口所在显示器的工作区归一化；启动时映射到当前主显示器，支持显示器禁用/启用及主副屏切换；旧版绝对坐标配置应可迁移，窗口恢复后完整可见且不小于现有最小尺寸。

**验收**：

- 在副显示器移动或调整窗口后，保存的矩形相对该显示器工作区计算；启动时使用同一组比例映射到当前主显示器。
- 同一比例矩形在 4K 与 2K 工作区间恢复时按比例调整位置和尺寸。
- 恢复后的窗口在当前主显示器上完整可见。
- 旧配置无效或尺寸异常时安全回退；`rememberWindowBounds=false` 行为不变。
- 回归测试覆盖归一化/恢复计算、屏幕变化与不可用屏回退；涉及 WPF/屏幕 API 的部分使用 STA harness 或可重复的替身输入测试。

## D2 保留并说明笔记目录导入标记

**现状**：`NoteStorage` 在将程序目录的旧 `notes/` 导入到不同的 `notesDir` 后，会在目标目录写入 `.flashsticknote`，以阻止后续重复导入。默认目标就是程序目录 `notes/` 时，不会创建该标记。

**目标**：保留 `.flashsticknote`，在文档中解释它是自定义 `notesDir` 导入旧默认笔记目录后的完成标记。默认目标为程序目录下的 `notes/` 时不创建该文件。不得改变现有导入或覆盖保护行为。

**验收**：

- 默认 `notes/` 初始化后没有 `.flashsticknote`。
- 自定义 `notesDir` 首次导入后会生成 `.flashsticknote`，用于阻止后续重复导入。
- 目标目录已有同名文件时不覆盖；标记存在时后续初始化不会再次导入。
- 在开发、配置和技术栈文档说明此文件不是笔记，且删除后可能使剩余的旧默认笔记再次进入导入流程。
- 添加临时目录存储回归，检查默认目录、首次导入、重复启动和目标冲突行为。
